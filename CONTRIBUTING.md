# Contributing

Thank you for contributing to the Hindi-English Code-Mixed NLP Toolkit.

## Development workflow

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Install dependencies from `requirements.txt`.
4. Add or update tests for behavior you change.
5. Run the test suite before opening a pull request.
6. Document research assumptions, datasets, and evaluation settings when relevant.

## Research contributions

For experiments, please report:

- Dataset source and licensing information
- Train/validation/test split
- Preprocessing steps
- Random seeds
- Model and hyperparameters
- Evaluation metrics
- Baselines used for comparison
- Known limitations

## Code quality

Prefer small, readable functions and avoid committing generated datasets, secrets, credentials, or environment-specific files.

## Pull requests

Keep pull requests focused. Explain what changed, why it changed, and how it was validated.
